# Ahead retailer pilot plan

## Pilot question

Does an own-photo wig and headwear preview help shoppers arrive at a fitting with clearer preferences, and does that make the specialist conversation more useful?

## First partner

Start with one independent wig specialist or retailer that already supports customers experiencing treatment-related hair loss. The partner supplies product data and a specialist who can judge whether the fitting brief helps in practice. A cancer-centre referral route can come later; the first pilot should stay close to the product and the buying decision.

## Data required to turn style directions into products

Each live item should have a partner-owned SKU, name, category, colour, product URL, current price, availability, cap construction/size, and a licensed reference image. The image must show a person wearing the item: Ahead's tested Hair Transfer flow rejects flat-lay and mannequin references because it cannot find a face. The partner confirms image rights and how often stock and price data refresh.

Until those fields and permissions exist, keep the current catalogue labelled illustrative and do not display estimated stock, prices, or retailer logos.

## Pilot measures

Set the baseline and success thresholds with the partner before launch. Compare the existing fitting journey with the Ahead-assisted journey using the same store and appointment period where possible.

| Measure | Definition |
|---|---|
| Preview completion | Sessions with at least one completed own-photo preview divided by sessions that begin a preview |
| Shortlist rate | Sessions that save at least one look divided by sessions that open the catalogue |
| Brief handoff rate | Fittings where the specialist opens or receives a brief divided by fittings started through Ahead |
| Fitting-to-purchase rate | Purchases divided by completed fittings, compared with the partner's agreed baseline |
| Consultation time | Median time from fitting start to a recorded shortlist or purchase decision |
| Return/exchange rate | Purchases later returned or exchanged divided by purchases in each measured group |
| Shopper usefulness | Optional one-question rating after a fitting: “Did this shortlist make it easier to discuss what you wanted?” |

Use the partner's own booking and point-of-sale records for appointment and purchase outcomes. Do not infer a conversion lift from preview counts alone. Report sample size and period with every result.

## Privacy boundaries

The first pilot should not send photos, treatment dates, treatment stage, names, or free-text health details to the retailer's analytics. The stylist brief contains only selected style directions, colour swatches, and optional notes. Collect aggregate funnel measures only with clear notice and consent, and set a short retention period with the partner before the test starts.

## Go/no-go decision

Proceed to a broader catalogue only if shoppers can reliably complete previews, specialists can map style directions to real SKUs, and the pilot shows a useful fitting outcome against the agreed baseline. If the handoff does not help, fix the catalogue or the fitting brief before claiming business impact.
