# Ahead demo — target 2:20 (hackathon limit: 1–3 minutes)

## One-sentence story

Ahead uses YouCam Hair Transfer to help people navigating treatment-related hair loss see wigs and wraps on their own photo, compare favourites, and take a fitting brief to a specialist.

## Record this flow

Use a consented portrait for live previews. Generate the renders before recording so the demo stays within time. Keep the same person visible in the original and every result. Do not show the preview code, API key, email, private images, or balance screen.

## Backup judge path

The landing page's **Explore sample previews** link opens recorded YouCam outputs on a sample portrait. It requires no upload, code, or API units. Say that the sample view replays saved results; do not describe it as a new live inference. The organizer has confirmed that a clearly identified replay of a real API response can be used for judge access.

## Evidence card (optional)

If there is room, show: “In one 2025 survey, 157 of 202 respondents receiving systemic therapy reported hair loss; 109 of those 157 bought wigs.” Keep the respondent count and the one-study caveat visible. Source: https://pubmed.ncbi.nlm.nih.gov/39891884/.
